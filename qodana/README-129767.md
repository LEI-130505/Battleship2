## 4. Reflexão (Passo 11)
A ferramenta foi eficaz a bloquear o Pull Request ao detetar uma classe com excesso de dependências externas (`Ce > 10`), o que é um claro indicador de Inappropriate Intimacy e forte propensão a Shotgun Surgery. No entanto, usar apenas o limite absoluto de acoplamento eferente penaliza injustamente classes como "Controladores" ou "Managers" centrais que, por natureza, precisam de orquestrar várias classes (embora o seu design deva ser vigiado). A impossibilidade de combinar o Acoplamento (Ce) com a Instabilidade ou o Acoplamento Aferente (Ca) no Qodana limita uma avaliação arquitetural verdadeiramente rigorosa.
