## 3. Limitações do Checkstyle (Passo 6)
O Checkstyle realiza apenas uma validação léxica baseada em expressões regulares. Isto significa que valida corretamente o formato do texto (se tem a letra maiúscula no início), mas não consegue avaliar a semântica. Não deteta se o nome é significativo no contexto do domínio (ex: uma classe chamada `A` passa na regra mas quebra o princípio dos Meaningful Names) nem avalia erros ortográficos.
